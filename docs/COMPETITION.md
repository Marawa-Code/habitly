# Konteks Lomba: Hackathon FIRETECH 2026

Lomba tingkat mahasiswa (D3/D4/S1) se-Sumatera Barat.

- **Tema:** *Harmonizing Tech and Humanity: Creating Solutions for a Better Society*. Solusi berbasis website atau aplikasi mobile untuk isu nyata di masyarakat.
- **Tim:** 3-5 orang dari perguruan tinggi yang sama. Hadir luring di Seminar PKM Universitas Andalas dengan laptop sendiri.
- **Studi kasus** baru diumumkan di hari pelaksanaan. Rancangan harus mudah diadaptasi.
- **Wajib unggah** source code dan tautan prototipe sebelum batas waktu. Area kerja dikunci pukul 21.00 WIB.
- **Presentasi:** 7 menit presentasi dan demo, lalu 13 menit tanya jawab dengan juri. Urutan tampil diacak.

## Kriteria Penilaian

| Komponen | Bobot | Cara Habitly menjawab |
|---|---|---|
| Inovasi dan orisinalitas | 30% | Latihan bertahap khusus kecemasan sosial dan komunikasi, bukan habit tracker umum |
| Relevansi tema dan solusi masalah | 20% | Teknologi untuk kebutuhan manusia: kepercayaan diri dan kesehatan mental remaja |
| Kualitas teknis dan eksekusi | 20% | Struktur kode rapi, konten terpisah dari kode, alur P0 stabil, UI mobile-first |
| Potensi dampak dan keberlanjutan | 15% | Rencana ukur lewat tugas selesai, streak, tren skor; peluang kerja sama sekolah |
| Presentasi dan demo | 15% | Alur demo jelas dari kuis sampai progres dalam 7 menit |

Setiap keluaran agent sebaiknya menyebut kriteria mana yang diperkuat.

## Demo 7 Menit (Target)

Alur harus berjalan mulus tanpa jaringan:

1. Masalah dan pembeda (±1 menit).
2. Onboarding, kuis, dan hasil (±1,5 menit).
3. Rekomendasi jalur dan tugas harian (±1 menit).
4. Selesaikan tugas dan isi jurnal (±1 menit).
5. Progres: streak, grafik tren skor, lencana (±1 menit).
6. Keamanan, etika, dan rencana dampak (±1 menit).
7. Penutup dan rencana lanjutan (±0,5 menit).

Siapkan akun demo dengan data contoh agar grafik dan lencana langsung terlihat.

## Risiko

| Risiko | Mitigasi |
|---|---|
| Dianggap habit tracker biasa | Tonjolkan jalur latihan bertahap khusus kecemasan sosial |
| Pertanyaan juri soal etika dan batas peran | Siapkan jawaban: alat bantu, bukan terapi; rujukan profesional; privasi |
| Komunitas memicu cemas | Anonim, pesan terpilih, tanpa peringkat |
| Waktu hackathon terbatas | Kunci P0, tunda P1 dan P2 |
| Studi kasus hari-H berbeda | Konten modular dan mudah diganti |
| Klaim data tidak berdasar | Hanya pakai statistik dari sumber resmi yang diverifikasi |
| Notifikasi PWA tidak andal | Jadikan P2 dan jelaskan sebagai rencana |
